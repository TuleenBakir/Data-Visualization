# Data-Visualization
NYC Yellow Taxi Data Quality Assessment
Overview
This project analyzes and validates the NYC Yellow Taxi dataset (Jan–Mar 2025) containing 11.2M+ records.
The goal is to identify data quality issues that impact business insights and prepare a clean, reliable dataset for analysis.

-Key Impact
Detected 38.7% inconsistency in total fare calculations
Identified 20% missing data due to vendor issues
Found critical logical errors (negative fares, impossible trips)
Improved dataset reliability for business intelligence reporting

-Key Data Quality Checks
Field Validity: Invalid categorical values
Numerical Errors: Negative/zero/impossible values
Temporal Issues: Incorrect timestamps & durations
Cross-Field Logic: Inconsistent financial calculations
Missing Data: Vendor-based missingness
Duplicates: Near-duplicate trip detection
